CLATTER 12

The CLATTER drum machine, native to the Plinky 12.

Seven voices of authentic LXR drum synthesis, a generative sequencer, and a 16 × 16 grid of pressure-sensitive pads. One custom panel, built into Plinky's own firmware.

01 The grid

This is the instrument's whole interface, drawn as the Plinky's pads look when lit. The pads work: build a pattern, press PLY and watch the playhead run. Hover or tap anything to read what it does. This page makes no sound; the engine's sound is in the clips further down.

A mouse has one pressure, so the slider stands in for how hard you press (a pen uses its real pressure). Holding a page pad and tapping another copies the page: on a touch screen use two fingers; with a mouse, Shift-click the first page pad to hold it. GEN and MUT replay patterns recorded from CLATTER's own generator. The panel makes them live and mutates whatever you've edited. Drawn from the Plinky 12's published layout (16 × 16 pads, four side buttons), not from a photograph.

02 Hear the engine

Each clip is CLATTER 12's engine rendering a pattern from CLATTER's generator with one of its designed kits: the same code the panel contains, run on a desktop at the Plinky's 32 kHz. They are not recordings of a Plinky, and the level is normalised.

03 What it is

Authentic LXR synthesis

The sound engine of Erica Synths' LXR-02 drum machine, unchanged, as in CLATTER and CLATTER Pocket. It runs at its own 44.14 kHz and is converted to the Plinky's 32 kHz, so pitch and decay stay exactly as the LXR makes them. It is not Plinky's synth with a new name.

6 VOICES · 7 TRIGGERS · VARIATIONS

A Plinky custom panel

One C++ file written for Plinky's public panel API. Plinky's IDE builds it into the firmware; nothing is replaced and the stock panels stay.

NATIVE · RP2350 · NO FIRMWARE SWAP

Generative sequencing

Eleven rhythm styles, mutation, and sixteen designed kits, all from CLATTER. Up to 64 steps on four pages.

GEN · MUT · KIT · UNDO

Built for the pads

Seven drum rows with a variation lane under each. How hard you press a step sets its velocity, and brightness shows it.

PRESSURE · RGB · 16 × 16

04 Status

UNVERIFIED

Nothing here has run on a Plinky 12. The emulator and the desktop tests are the evidence so far.

WhereResult
Desktop testsPass. The engine matches CLATTER Pocket's reference build (spectra within 0.03 dB per band), the 32 kHz conversion is clean, and 3,200 of 3,200 generated patterns and kits are identical to Pocket's.
Cortex-M33 compileCompiles for the RP2350's core with GCC. About 51 KB of code, 21 KB of constants, no software double-precision on the audio path.
Plinky's emulatorCompiles, links, boots and runs with no audio underruns over four minutes. The CPU readout shows 0 there, and 17 samples clipped while editing.
A Plinky 12Never run. CPU load on the audio core is the open question: it decides whether all seven voices fit.
Saving, MIDI, CVNot built yet.

05 Try it

You need a computer and Plinky's code editor. No hardware.

  1. Get the source: git clone --recurse-submodules https://github.com/clickysteve/clatter-12
  2. Build the panel and run the tests: make. It writes build/clatter_12.cpp.
  3. Open Plinky's code editor (closed beta: access comes from their Discord), paste the file into a new tab, press Test.
  4. Play: PLY starts the beat, a hard press makes a loud step, the lane under a step cycles its variation, GEN and KIT change the pattern and the sound.
git clone --recurse-submodules https://github.com/clickysteve/clatter-12
cd clatter-12
make            # builds build/clatter_12.cpp and runs every host test

Don't flash a Plinky with it yet. The project's rules: no hardware claims without a device, and nothing touches the bootloader.
