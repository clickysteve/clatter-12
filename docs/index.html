CLATTER 12

The CLATTER drum machine, native to the Plinky 12.

Seven voices of authentic LXR drum synthesis, a generative sequencer and procedural kits on a 16 × 16 grid of pressure-sensitive pads. Five pages: SEQ, SOUND, GEN, MIX, FX. One custom panel, built into Plinky's own firmware. Play it below: the page runs the panel's own code.

01 Play it

This grid is the panel's own interface: CLATTER 12's firmware source, engine and all, compiled to WebAssembly with a stand-in for the Plinky's API, so every pad does here exactly what it does in the firmware. Tap a pad to put a step in, press PLY (bottom right), and use row 15's first six pads to change page. Hover or tap anything to read what it does.

It is an interface demonstration, not a Plinky: no pressure sensor, no Plinky delay or reverb (the sends are silent here), no CPU limit, and it says nothing about how the hardware will perform.

SAVE PAGEOn a Plinky this is Plinky's own save and load page: CLATTER 12 writes the whole project to a song slot. Here, use SAVE PROJECT and LOAD PROJECT below (the same file).

A mouse has one pressure, so the slider stands in for how hard you press (a pen uses its real pressure). Two-handed gestures (hold a step and tap the editor rows below it; hold a page pad and tap another to copy) work with two fingers on a touch screen; with a mouse, Shift-click a pad to keep it held, and RELEASE HELD lets go. SAVE PROJECT downloads the very JSON the panel gives Plinky's save page.

02 What it is

Authentic LXR synthesis

The sound engine of Erica Synths' LXR-02 drum machine, unchanged, as in CLATTER and CLATTER Pocket. It runs at its own 44.14 kHz and is converted to the Plinky's 32 kHz, so pitch and decay stay exactly as the LXR makes them. It is not Plinky's synth with a new name. The page above runs this same code as WebAssembly.

6 VOICES · 7 TRIGGERS · VARIATIONS

SEQ: rhythm first

Seven LXR triggers by 16 steps. Tap a pad on, tap it off; hold it to edit it: variation, condition (1:2 to 4:4, chance), ratchet up to 8×, roll spacing and velocity run. No variation lanes: the freed rows are the step editor, mute, solo, lock, length and swing.

PRESSURE · CONDITIONS · RATCHETS

SOUND: the LXR, a row each

Every LXR parameter of the chosen voice, one row each, its value across the columns, in three banks: SOURCE, SHAPE, MOD. Menus show their options. Heard at once; audition without leaving.

33 PARAMETERS A VOICE · FINE ± · AUDITION

GEN: patterns and kits

CLATTER's pattern generator (eleven styles, density, complexity, mutation, one track at a time) and its kit designer: a new kit, a new sound, mutate a kit or a sound, with wildness, amount and locks. Every result is a new design, not a preset. Undo and redo.

PROCEDURAL · LOCKS · UNDO

MIX and FX

Channel strips: level, pan, mute, solo, delay and reverb sends into Plinky's own effects, master. The LXR-02's own drive, ring modulator and compressor on the tracks you route, bit and sample-rate reduction, and a limiter.

REAL AUDIO · NOT JUST LIGHTS

03 Status

UNVERIFIED

Nothing here has run on a Plinky 12. The emulator and the desktop tests are the evidence so far.

WhereResult
Desktop testsPass. The engine matches CLATTER Pocket's reference build (spectra within 0.03 dB per band); the panel passes 127 scripted checks in CLATTER 12's simulator of the Plinky API: steps, variations, conditions over whole passes, ratchets, kits, mixer, FX, saving and loading, undo.
Cortex-M33 compileCompiles for the RP2350's core with GCC: about 89 KB of code and 27 KB of constants for engine and panel, no software double-precision anywhere.
CPU (an estimate)Tight. In QEMU's Cortex-M33 model the engine runs about 168,000 instructions per 2 ms audio block on average and 244,000 in the busiest (two LXR blocks). At 150 MHz that is at least 56 % and 81 % of the audio core before memory wait states. Only a Plinky can say if it fits.

04 Try it

You need a computer and Plinky's code editor. No hardware.

  1. Get the source: git clone --recurse-submodules https://github.com/clickysteve/clatter-12
  2. Build the panel and run the tests: make. It writes build/clatter_12.cpp.
  3. Open Plinky's code editor (closed beta: access comes from their Discord), paste the file into a new tab, press Test.
  4. Play: PLY starts the beat, a hard press makes a loud step, holding a step lets the rows under it change it, and row 15 moves between SEQ, SOUND, GEN, MIX, FX and SAVE.
git clone --recurse-submodules https://github.com/clickysteve/clatter-12
cd clatter-12
make            # builds build/clatter_12.cpp and runs every host test

Don't flash a Plinky with it yet. The project's rules: no hardware claims without a device, and nothing touches the bootloader.
